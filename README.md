# OCI Panel 2.2

只管理 Oracle Cloud 的自托管面板。管理员在自己的服务器登录，OCI API 私钥保存在本地数据库，不需要 Telegram、第三方账号激活或购买面板权限。

## 私密入口与登录

首次安装或从旧版升级后的首次启动会在服务器本地生成 **32 位随机入口、32 位随机用户名和 32 位随机密码**。旧版的单密码登录及旧 Cookie 会失效，云账号和 SSH 数据不变。只在服务器上查看：

```bash
cat /root/oci/data/initial_admin_credentials.txt
```

浏览器访问 `https://你的域名/随机入口/`，再输入用户名和密码。域名根目录、旧的 `/api`、`/static`、`/ws` 和 `/mcp` 地址不提供面板内容；只有 `/healthz` 保留给本机健康检查。随机入口只是减少暴露，仍需登录和 HTTPS。不要把完整入口链接、登录文件或 `data/` 上传到 GitHub，也不要把它们发送给别人。

在 1Panel 建立 HTTPS 反向代理时，把整站请求路径原样转发到面板，保留 Host 与 WebSocket Upgrade；不要只代理入口首页，否则接口和 SSH 终端会失败。启用 HTTP 自动跳转 HTTPS 或禁用 HTTP，并给 systemd 服务加 `COOKIE_SECURE=1`。确保面板端口只对反代可达，不直接暴露公网；如果 1Panel 的 OpenResty 在容器里，先确认它能访问你选择的面板监听地址。修改密码后初始凭据文件会删除，请自行保存入口和用户名。

## 2.2 界面与监控

### 代理失败时禁止直连

云账号填写出站代理后，每一个 OCI SDK HTTP/HTTPS 请求（含重定向）都会强制使用该代理，忽略系统代理环境变量；代理配置异常或连接失败会报错，禁止回退到 VPS 直连。`socks5://` 自动按 `socks5h://` 使用，使目标域名在代理端解析。

SSH 的代理栏可以填 `socks5h://地址:端口` 或 `socks5h://用户名:密码@地址:端口`，用户名/密码中的特殊字符应进行 URL 编码。旧的 `nc -x 地址:端口 %h %p` / `nc -X 5 -x 地址:端口 %h %p` 会自动转换为原生 SOCKS5 连接，无需安装 nc。任意其他代理命令会被拒绝，避免命令自行绕过代理。主机公钥检查、终端、SFTP、批量命令、资源监控和端口转发都使用同一条受控连接路径。代理不可达或认证失败时禁止建立目标连接，代理连接中断后 SSH 关闭；长时间无响应通过 SSH 保活检测断线。

云账号和 SSH 会话的代理分别配置，不会自动互相继承；未填写代理的配置仍然直连。本功能确保面板通过指定代理建立连接，不能验证代理商是否使用你期望的最终出口 IP，也不改变本机浏览器打开网页链接的路径。

每个云账号独立创建 SDK 客户端并固定自己的出站路径。留空代理时明确直连，不继承服务器的 HTTP_PROXY / HTTPS_PROXY / ALL_PROXY；一个账号的代理失败不会改变其他账号的路径。不同 SSH 会话也分别连接，代理断线只关闭受影响的连接。这是连接与代理配置隔离，各账号仍运行在同一台 VPS 上。

修改已保存 SSH 会话的代理会关闭旧连接，必须重新打开终端。连接过程中代理配置被改变也会拒绝沿用旧设置。删除会话会关闭该会话的现有连接。

多账号代理隔离已用两个独立本地 SOCKS5 代理验证：两个账号并发发送带各自身份签名的 HTTPS 请求、跨主机重定向仍各走各自代理，故障代理不会回退直连，也不会改变另一个账号的线路。系统代理环境变量不会覆盖账号配置。这里隔离的是 SDK 客户端、签名身份和网络线路；不是独立操作系统、容器或机器指纹。实际公网出口是否不同取决于你购买或部署的代理，本地验证不代表已检测你的代理出口。

停止或删除尚未执行的抢机任务后，后台会跳过该任务。正在提交 OCI 的任务返回明确的操作冲突提示，需等本次结果后再操作；云端已接收的请求无法撤回。MCP 与网页共用手动停机记录，避免被自动拉起。修改密码后，旧 SSH 终端也会断开。

Cloudflare 凭据可在「设置」保存和测试，空白密钥保留已有值，删除需要明确勾选。优先使用 API Token；同时保存 Token 和 Global Key 时优先使用 Token。MCP 完整入口会在设置页按当前域名与随机入口生成。对象存储文本预览只读取最多约 2 MB，不再下载整个大对象。

侧边导航、浅色/深色切换、适配窄屏。顶部每 3 秒读取部署服务器 CPU、内存、网络速率和面板进程内存；第一次采样的 CPU/网络显示待采样。Linux 从 /proc 读取，cgroup v2 可用时按照容器/LXC 限额显示；其他系统显示不可用。鼠标悬停可查看磁盘容量。网络速率合计非回环接口，并排除常见 Docker 桥接与 veth 接口。

概览的成本、24 小时出站流量、区域订阅和计算配额卡片点击「读取」后查询 OCI，不需要任何付费解锁。区域订阅指 OCI 已订阅的区域。成本保留 OCI 返回的币种，费用可能有延迟；未收到实例监控指标时明确显示无数据。权限不足会显示云端错误，不以 0 冒充成功。新增「配置体检」和「云监控」，仅执行只读查询。

SSH 会话支持搜索、复制地址、复制会话、终端关闭和断线后重新连接。复制凭据在服务器端完成，浏览器只收到隐藏后的凭据。云实例同步会更新保存的 OCI 规格；未知的系统或磁盘容量不填入示例值。在线状态仅表示当前终端连接状态或最近一次测试结果。旧数据库第一次启动会自动添加 metadata 字段，已有会话和密钥保留。

SSH 终端排在导航最前面，登录默认进入 SSH 工作台；打开的终端显示在会话列表上方。标签栏显示连接状态，可切换、关闭，支持全屏工作区（Esc 还原）、清屏、回到底部和下方 SFTP 面板。终端颜色随浅色/深色主题切换。选中终端文字后右键复制，或用 Ctrl+Shift+C；Ctrl+左键打开 http/https 链接，普通单击不会跳转。链接由本机浏览器打开，其网页请求使用浏览器自身网络，不经过 SSH 面板服务器；这不改变面板的后端 SSH/API 连接路径。

界面使用本地资源，不载入外部字体、统计或遥测，也不会把浏览器 IP 转发给 OCI。SSH/API 连接仍从部署面板的服务器发出。

终端右键：有选中文字时复制，没有选中文字时粘贴剪贴板文字。粘贴不会额外补回车，保留 xterm 的括号粘贴模式。若浏览器拒绝读取剪贴板，可允许站点剪贴板权限或用 Ctrl+V；HTTP 公网地址可能没有剪贴板读取 API，localhost SSH 隧道或 HTTPS 可用。

### SSH 工作台交互

SFTP 上传显示当前文件的传输百分比与已发送大小。100% 表示浏览器发送完成，界面会继续等待远程写入确认；只有收到成功响应才显示上传完成，失败时显示错误。多个文件依次上传，每个文件仍限制为 100 MB。

鼠标在终端文字区中滚动时只滚动终端历史，到顶/到底不会带动整个页面；鼠标移到工具栏或窗口外可以正常滚动页面。全屏时锁定背景页面滚动，Esc 或关闭最后一个终端后恢复。SFTP 文件列表可以独立上下滚动，支持上一级和刷新；打开目录失败时保留原目录并显示错误原因，避免后续操作使用错误路径。添加/编辑会话、端口转发、批量命令和资源监控面板显示在工具按钮下方，并自动滚动到可见位置。

连接 SSH 后，当前选中终端上方自动显示 CPU、内存、根目录磁盘和网卡累计收发数据，每次采集完成后约 5 秒再次刷新。同一时间只轮询当前终端，切换标签会切换目标并忽略旧请求结果；关闭、断线、离开 SSH 页面或浏览器进入后台后停止自动轮询。已经发送到后端的采集会自行完成并关闭连接，不再继续发起下一次。自动采集通过该 SSH 会话自身的代理/直连设置单独建立连接，不继承概览云账号的代理。网卡累计值不是即时网速，实时刷新不等于开启后台超限告警。

## Linux + Docker 部署

把修复版项目文件放到服务器的 `oci-panel` 目录，进入目录执行：

```bash
docker compose up -d --build
docker compose ps
docker compose exec -T oci-panel cat /app/data/initial_admin_credentials.txt
```

按文件中的随机入口访问，使用生成的用户名和密码登录。修改密码会使原有登录失效，需重新登录；初始凭据文件也会删除。

面板未内置 TLS，建议使用 HTTPS 反向代理；示例在 `deploy/nginx.conf.example`。反向代理时保留 Host、完整请求路径和 WebSocket Upgrade 头。只开放反代端口，面板端口不要对公网开放。

登录限流依赖真实客户端 IP。示例 Nginx 会用 `$remote_addr` 覆盖 `X-Forwarded-For`，避免客户端伪造。直接由同机 Nginx 转发到 Python 时默认信任 `127.0.0.1`；Docker/容器反代场景，需将 `.env` 的 `FORWARDED_ALLOW_IPS` 设置为面板实际看到的可信反代来源 IP，重建容器后生效。systemd 部署可通过服务环境变量配置同名选项。不要设置为 `*`，也不要信任任意公网来源；多个可信来源可用逗号分隔。

默认保存目录是项目中的 `data/`，Docker 自动挂载到 `/app/data`。更新项目、重建容器不会清除这个目录。请保留并备份整个目录，里面有账号私钥、SSH 凭据和面板设置。

可选：复制 `.env.example` 为 `.env`，修改端口或监听地址。只有在已经配置 HTTPS 后才设置 `COOKIE_SECURE=1`。

## 添加 OCI 账号与创建实例

1. OCI 控制台的用户/API 密钥页面添加 API 密钥，取得 User OCID、Tenancy OCID、指纹和对应的 PEM 私钥。
2. 「云账号」添加账号，填名称、区域以及以上配置，保存并点击「测试」。这是 **OCI API 私钥**，不同于用于登录虚拟机的 SSH 密钥。
3. Compartment OCID 留空时只查询租户根目录；资源在子 compartment 中时必须填写那个 compartment 的 OCID。一个账号配置对应一个区域，可复制到其他已订阅区域。
4. 「开机抢机」选择账号和规格，选择已有公网子网。如果没有子网，点击「创建公网网络」；会创建带 `oci-panel=managed` 标记的 VCN、互联网网关及公网子网，并开放 SSH 22 端口。它只管理面板创建的网络。
5. 填写 **SSH 公钥**（例如 `ssh-ed25519 ...`），创建任务。创建后用对应 SSH 私钥登录；Ubuntu 镜像通常使用 `ubuntu` 用户，Oracle Linux 使用 `opc`。
6. 任务遇到容量不足/限流/临时网络错误会重试，成功后停止。成功任务不能再次恢复，创建另一台应新建任务。从已有引导卷创建时固定使用那个卷所在的可用域。

OCI API 权限由你的 IAM 策略决定。计算、网络、卷、对象存储、监控、用户和邮件管理可能需要不同权限。401 通常是密钥配置问题；403/404 也可能表示区域、compartment 或权限不匹配。面板免费不代表所有 OCI 资源免费：创建、扩容、提升磁盘性能前应确认账号额度。

### 重建与自动重启的行为

「重建」按旧实例的镜像/规格创建替代实例，**保留旧实例和全部旧数据**，不会自动终止旧机。需要额外配额，公网 IP 也会改变。确认新实例能登录后，再手动释放旧资源。这不是保留实例 OCID 的原地重装。

手动关机、流量超额关机不会被「自动拉起」再次启动。流量关停后应在确认原因后手动启动；关闭流量关停策略会取消该策略的启动阻止记录。

SSH 首次成功连接会记录服务器主机公钥，后续公钥不匹配将拒绝连接。重装真实服务器后，先核实主机身份，再在面板点击「重置信任」。

「串口日志」提供启动日志，不是交互式串行救援终端；不会宣称与参考项目全量功能一致。网络高级规则、自动 TLS 签发和交互串行控制台仍需 OCI 控制台或其他工具处理。

## 漫画分镜主题

当前面板使用本地漫画主题：`static/manga.css` 负责面板适配，`static/manga-layout.css` 提供通用分镜和对话气泡样式。重点区域全宽显示，会话和概览卡片使用不同宽度的 CSS Grid 分镜；边框为 3px 黑色实线，桌面悬停轻微旋转，手机自动单列。终端不旋转，支持浅色、深色和减少动态效果设置。图片素材是本地原创 SVG，没有外部字体或图片请求。
